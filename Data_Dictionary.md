# Data Dictionary

Mobile Sales Data.xlsx`.

| Column | Description |
|---|---|
| Brand | Mobile brand (Apple, Samsung, OnePlus, Vivo, Xiaomi) |
| Mobile Model | Phone model sold (e.g., Galaxy Note 20, Galaxy S21, Galaxy A51) |
| Quantity / Total_quantity | Number of units sold |
| Price | Unit price of the phone |
| Total_sales | Revenue (quantity x price) |
| Transaction | Count of sales transactions |
| Payment Method | UPI, Debit Card, Credit Card or Cash |
| City | City where the sale occurred |
| Month | Month of sale (January - December) |
| Day Name | Day of the week of sale |
| Customer Rating | Customer rating from 1 to 5 |
